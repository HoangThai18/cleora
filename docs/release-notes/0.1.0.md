Bản đầu tiên của Cleora: dọn dung lượng Windows miễn phí, quét trước, bạn chọn rồi mới xoá.

- Dọn rác: file tạm, bản tải Windows Update, bộ nhớ chia sẻ cập nhật, báo lỗi, bản ghi lúc sập, ảnh thu nhỏ, nhật ký cài đặt; Thùng rác, bản Windows cũ (Windows.old) và bộ nhớ đệm đồ hoạ khi bạn chọn
- Trình duyệt và app: bộ nhớ đệm Chrome, Edge, Cốc Cốc, Brave, Vivaldi, Opera, Firefox, Discord, Zalo, Teams, Slack, VS Code, Messenger, Steam. Không đụng mật khẩu, cookie, lịch sử, tin nhắn
- File lớn: thư mục và file chiếm nhiều chỗ nhất trên từng ổ, chuyển vào Thùng rác
- File trùng: so cả nội dung trong Tài liệu, Ảnh, Video, Nhạc, Tải về, Màn hình nền (bỏ qua dữ liệu app), chọn sẵn bản thừa, luôn giữ lại một bản; file trên ổ rời không bị xoá
- Gỡ ứng dụng: app xếp theo dung lượng, mở bộ gỡ của app
- Khởi động: bật/tắt app chạy cùng Windows như Task Manager
- Giao diện sáng và tối, theo màu của Windows
- Cập nhật ngay trong app: có bản mới thì bấm Cập nhật ở Cài đặt
